# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or include
account state, cryptographic material, message content, phone numbers, or pairing
QR codes in a report.

Use GitHub's private vulnerability reporting for this repository:

<https://github.com/bryantebeek/omarchy-whatsapp/security/advisories/new>

Include the affected version, impact, reproduction steps using fictional data,
and any suggested mitigation. You should receive an acknowledgement within
seven days. There is currently no long-term-support release branch; security
fixes target the latest release and `main`.
